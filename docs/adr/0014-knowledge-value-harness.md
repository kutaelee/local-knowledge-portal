# ADR 0014: 지식 가치 하니스와 길이 독립 편집

- 상태: Accepted
- 날짜: 2026-07-24
- 관련 ADR: 0006, 0013

## 배경

본문의 최소 글자 수는 지식 가치를 측정하지 못한다. 작은 로컬 모델에 최소 분량을
요구하면 같은 사실을 반복하거나 근거에 없는 맥락을 보충할 가능성이 커진다. 반대로
짧더라도 실패·원인·조치·검증이 명확한 기록은 재사용 가치가 있다.

모델이 모든 활동의 가치를 처음부터 판단하게 하는 것도 적절하지 않다. 실행 근거의
종류와 순서는 애플리케이션이 더 정확히 판정할 수 있으며, 이 신호는 후보 생성 시점과
최종 Markdown 인덱싱 시점에 모두 보존할 수 있다.

## 결정

`knowledge-value-v1` 결정론적 하니스를 LLM 편집보다 먼저 실행한다.

- 오류 해결은 검증된 실패, 파일 또는 문서 변경, 성공한 검증과 재사용 가능한
  원인·조치 설명이 모두 있어야 `promote`다.
- 구현 방식은 검증된 변경과 테스트·빌드·검증, 재사용 가능한 구현 판단이 모두
  있어야 `promote`다.
- 성능 사례는 `performance_before`, `performance_after`, `load_cause`가 모두 있어야
  `promote`다.
- 운영 사례는 `incident_failure`, `recovery_success`가 모두 있어야 `promote`다.
- 구조적 판단이 없는 단순 CSS 변경은 `activity_only`다.
- 실행 근거가 없거나 필수 신호가 부족한 항목은 게시하지 않고 `needs_review` 또는
  `activity_only`로 유지한다.

판정 결과에는 `tier`, `signals`, `blockers`, `embedding_labels`, 하니스 revision을
기록한다. 최종 관리형 Markdown frontmatter에도 `knowledge_value_tier`와
`knowledge_value_labels`를 기록하므로 임베딩 및 하이브리드 검색에서 일반 활동과
재사용 가능한 사례를 구분할 수 있다.

LLM은 `promote` 후보만 근거 기반 글로 편집한다. 모델은 문단 텍스트와 근거 ID를
구조화해서 반환하고, 실제 `[E1]` 인용 표기와 Markdown 렌더링은 결정론적 코드가
담당한다. 모델이 유효하지 않은 구조를 반환하면 허용 근거 ID와 스키마 오류만 제공하는
교정을 한 번만 수행한다. 두 번째도 실패하면 모델 또는 후보를 fail closed 처리한다.

본문에는 최대 글자 수만 적용한다. 최소 글자 수, 문단당 최소 글자 수, 분량 채우기
지시는 사용하지 않는다. 대신 다음을 검사한다.

- 게시 글의 여섯 섹션 존재
- 각 문단의 유효한 근거 ID
- 문단 숫자와 인용 근거의 정확한 숫자 일치
- 확인되지 않은 추론과 과장 표현 부재
- 최소 두 종류의 근거 사용
- 실행 evidence gate와 지식 가치 하니스 모두 통과

## 결과

글의 길이는 가치 판정에 영향을 주지 않는다. 단순 활동은 임베딩 가능한 정식 사례로
승격되지 않으며, 유용한 사례에는 왜 승격됐는지 검색 가능한 신호가 남는다. 모델 크기는
문장 품질에 영향을 줄 수 있지만 게시 자격과 provenance를 우회할 수 없다.
